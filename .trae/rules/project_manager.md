# Project Management Protocol
- **State Awareness**: Before starting ANY task in Builder Mode, read `.trae/rules/backlog.md` to identify the "Siguiente Prioridad Recomendada".
- **GitHub Integration**: When a task is related to an Issue, use the GitHub extension context to read the issue description.
- **Update Cycle**: After finishing a feature, ask the user: "Should I update the 'Completado' section in backlog.md?"
- **Atomic Commits**: Suggest a commit message that references the task being worked on in the backlog.
